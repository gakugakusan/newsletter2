# ニュースを聴こう — 試作版

## 現在できること
- サンプル見出しの順次読み上げ
- 画面の「聴く」ボタンで個別読み上げ
- 対応ブラウザーで「2番」「次」「最初から」などの音声コマンド
- 貼り付けた文章の読み上げ
- 見出しリストを手動入力して動作確認
- PWA用 manifest / service worker

## まだ実装していないこと
- 読売新聞オンラインからの最新見出し自動取得
- 記事本文の自動取得・自動要約
- 公開URLへのデプロイ

新聞社の記事を無断で転載・再配信しないよう、次の段階では公式に利用可能なフィードや許諾済みAPIを優先します。現状はサンプル見出しを使うUI試作です。

## 起動方法
PWAとしてホーム画面に追加するにはHTTPSで公開する必要があります。index.htmlを直接開く場合、読み上げ機能の一部は試せますが、ホーム画面追加やService Workerは動作しない場合があります。
GitHub Pages等のHTTPSホスティングへ配置後、AndroidのChromeで開き、メニューから「ホーム画面に追加」を選んでください。
